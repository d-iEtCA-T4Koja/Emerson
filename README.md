# pembersih-android

![Tampilan](https://cdn.example.dev/shots/cleaner-screen.png)

Aplikasi ini dibuat belasan tahun lalu dengan satu tujuan sederhana: membuat ponsel yang mulai lambat terasa lebih ringan.

## Isi fitur:
* Menghapus aplikasi yang tidak dibutuhkan.
* Membersihkan berkas cache milik aplikasi maupun peramban.
* Membuang riwayat papan klip dan riwayat penjelajahan.
* Menghapus catatan panggilan dan pesan singkat.
